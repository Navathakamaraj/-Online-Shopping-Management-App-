
# 🛒 Online Shopping Management

A **Java console-based application** for managing products and cart billing in an online shopping scenario.  
This project demonstrates object-oriented programming concepts with a simple, menu-driven workflow.

---

## ✨ Features
- Admin login with password protection  
- Add, view, and delete products  
- User cart operations (add/view items)  
- Generate bill for cart items  
- Reusable menu-driven console workflow  

---

## 📂 Project Structure
- **`Main.java`** – Application entry point and console workflow  
- **`Product.java`** – Product model class  
- **`Cart.java`** – Cart item model with billing helper  
- **`User.java`** – User model class  

---

## ⚙️ Requirements
- Java JDK 8 or later  
- Command Prompt, PowerShell, or any Java-supported IDE  

---

## ▶️ Compile and Run
Open a terminal in the project folder and run:
```bash
javac *.java
java Main
```

## 📋 Usage
1. Run the application.  
2. Choose **Admin login** or **User menu**.  
3. Admin can add, view, and delete products.  
4. User can view products, add items to cart, and calculate the bill.  
5. Choose **Exit** to close the application.  

---

## 📝 Notes
- Products and cart items are stored in memory during a single run.  
- Data is **not persisted** between application restarts.
